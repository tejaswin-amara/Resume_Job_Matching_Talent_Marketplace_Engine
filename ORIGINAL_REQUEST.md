## Requirements

### R1. Backend API & Data Layer
A FastAPI application with PostgreSQL (pgvector extension) serving REST endpoints for:
- Resume upload/parsing (PDF, DOCX, text) with file validation and sanitization
- Job posting CRUD with search and pagination
- Candidate-job matching that returns ranked results with score breakdowns
- Health check endpoints for operational monitoring

Data layer includes: Candidates, Resumes (with vector embeddings), Job Postings (with vector embeddings), Skills, and Match Results. Schema managed by Alembic migrations. A seed script populates realistic test data.

### R2. ML/NLP Matching Engine
A hybrid scoring engine combining four weighted signals into a final ATS score (0-100):
- **Semantic similarity** (40% weight): cosine similarity between resume and job embedding vectors generated by a sentence-transformer model, stored in pgvector
- **Skills match** (35% weight): overlap between candidate skills and job required/preferred skills
- **Experience alignment** (15% weight): calibrated score based on candidate vs. required years of experience
- **Education fit** (10% weight): normalized credential match

Resume parsing extracts structured entities: skills (mapped to a taxonomy), years of experience, education level, contact info. Each match result includes explainability output: matched skills, missing skills, improvement suggestions, and per-signal score breakdown.

### R3. Frontend Dashboard
A Next.js/React TypeScript web application with:
- **Candidate portal**: upload resume, view parsed profile with extracted entities, see matching jobs with ATS diagnostic feedback
- **Recruiter portal**: post job requisitions, trigger talent matching, view ranked candidate leaderboard with skill gap visualization

Dark-mode-first design, responsive layout, Tailwind CSS styling.

### R4. Infrastructure & Quality
- Docker Compose orchestration: backend, frontend, PostgreSQL/pgvector, all with health checks
- Comprehensive test suite covering parsing, scoring math (boundary conditions, zero-division), and API endpoints
- Python linting/formatting with ruff, TypeScript with biome
- CI pipeline (GitHub Actions) running lint, test, security scan, and Docker build
- Repository governance: README with architecture overview and quick start, .env.example, .gitignore
