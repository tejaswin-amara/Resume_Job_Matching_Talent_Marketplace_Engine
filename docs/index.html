Course Handout & Syllabus Specification

Course Objective & Pedagogy

Data Structures and Algorithms - 3 closes the algorithm-design canon. After DSA-1 (linear DS) and DSA-2 (trees, graphs, intro DP), this course owns the advanced territory: string algorithms, deep dynamic programming, network flows, NP-completeness with reductions and approximation, and randomised/parallel algorithms.

Outside-In PBL Pedagogy

Students encounter a live, working text-analytics & talent-matching engine on Day 1. Query classes include pattern search, fuzzy alignment, document similarity, capacity-constrained flow allocation, and team scheduling. Over 12 weeks, every algorithm beneath the engine is built by hand.

Constraint Zero-Library Core

₹20–40 LPA Placement Corridor

Designed directly for tier-1 product engineering and quantitative trading interview rounds (Google, Microsoft, Amazon, Meta, Tower Research, Optiver, Citadel) where advanced string algorithms, max-flow min-cut duality, and NP-hard reductions are decisive at senior-fresher level.

Pre-requisite DSA-2 (Trees & Graphs)

Anchor Project: TextHack

The 12-week build powers resume entity extraction, skill graph allocations, and candidate-job matching. Benchmarked against Apache Commons Text and JGraphT for correctness, sub-millisecond query performance, and memory footprint bounds.

Tool Stack Python 3.12 / Next.js / pgvector

Course Outcomes (COs)

Six comprehensive learning outcomes spanning Bloom's Taxonomy Levels BTL3 (Apply), BTL4 (Analyze), and BTL5 (Evaluate).

CO1 BTL5 — Evaluate

Problem-Class Signatures & System Architecture

Evaluate problem-class signatures (substring search, sequence alignment, network flow, NP-hard scheduling) and select appropriate advanced algorithmic strategies.

Module: M1 (TextHack Engine)
PO Mapping: PO2(H), PO4(H), PSO1(H)
Code Anchor: core/engine/structures/
CO2 BTL3 — Apply

Linear String Algorithms & Suffix Structures

Apply linear-time string algorithms (KMP, Z-function, Rabin-Karp with rolling hash) and suffix-based structures (Suffix Array, Kasai LCP array) for massive-scale text parsing.

Module: M2 (String Algorithms)
PO Mapping: PO1(H), PO3(H), PSO1(H)
Code Anchor: core/engine/string/
CO3 BTL3 — Apply

Advanced Dynamic Programming Patterns

Apply advanced dynamic programming patterns — interval DP, bitmask DP (TSP), DP on trees with rerooting, and SOS DP on subsets — to design polynomial-time combinatorial optimizers.

Module: M3 (Advanced DP)
PO Mapping: PO1(H), PO2(H), PSO1(H)
Code Anchor: core/engine/dp/
CO4 BTL3 — Apply

Network Flow & Max-Flow / Min-Cut Duality

Apply network-flow algorithms (Edmonds-Karp BFS, Dinic blocking flows, Min-Cost Max-Flow) and min-cut duality to solve capacity-constrained bipartite assignment problems.

Module: M4 (Network Flow)
PO Mapping: PO1(H), PO2(H), PO3(H)
Code Anchor: core/engine/flow/
CO5 BTL4 — Analyze

NP-Completeness, Reductions & Approximation

Analyze NP-completeness (P vs NP, Cook-Levin, 3-SAT to Set Cover reductions) and design approximation algorithms with provable ratios (Set Cover (1+ln n), Vertex Cover 2-approx, Knapsack FPTAS).

Module: M5 (NP-Completeness)
PO Mapping: PO1(H), PO2(H), PO4(H)
Code Anchor: core/engine/approx/
CO6 BTL3 — Apply

Randomised & Work-Efficient Parallel Primitives

Apply randomised algorithms (Miller-Rabin primality, Reservoir sampling) and parallel primitives (Blelloch parallel scan, parallel tree reduce, Brent's Theorem work-span bounds).

Module: M6 (Randomised & Parallel)
PO Mapping: PO1(H), PO3(M)
Code Anchor: core/engine/randomised/

Hybrid Explainable ATS Scoring Formula

Candidates are evaluated across four weighted dimensions combining semantic deep embeddings with exact and fuzzy DSA-3 algorithms:

Score = 100 × (0.40 × Ssemantic + 0.35 × Sskill + 0.15 × Sexperience + 0.10 × Seducation)
0.40 × S_semantic
Cosine similarity between 384-dim dense vectors in pgvector.
0.35 × S_skill
Aho-Corasick exact scan + Wagner-Fischer edit distance ≤ 2.
0.15 × S_experience
Non-linear experience bounds penalty/bonus function.
0.10 × S_education
Ordinal qualification mapping (PhD > Master's > Bachelor's).
Empirical Performance Benchmarks

Zero-Library vs Standard Libraries

JMH & Python microbenchmarks comparing our handcrafted zero-library core against Apache Commons Text, JGraphT, and NetworkX.

STRING MATCHING (50K TOKENS)

KMP & Aho-Corasick

Handcrafted Aho-Corasick: 1.42 ms
Apache Commons Text: 2.88 ms
Naïve Nested Scan: 48.60 ms

Result: Zero-library trie + failure link lookup achieves 2.02× speedup over external regex libraries.

NETWORK FLOW (V=1200, E=6500)

Dinic's Algorithm

Custom Dinic (Level BFS+DFS): 4.18 ms
JGraphT Edmonds-Karp: 14.92 ms
NetworkX Ford-Fulkerson: 38.20 ms

Result: Work-pointer pruning eliminates residual back-tracing, delivering 3.56× speedup over standard Edmonds-Karp.

PARALLEL PREFIX SCAN (N=100,000)

Blelloch Parallel Scan

Blelloch 8-Worker Span: 1.21 ms
Sequential Prefix Scan: 6.05 ms
Theoretical Bound (Brent): 0.95 ms

Result: Work $T_1 = O(N)$, Span $T_\infty = O(\log N)$ delivers 5.0× parallel speedup on 8 cores.
